# Assets

Shared brand assets for Roulette.

| File | Use |
|------|-----|
| `logo.svg` | Master logo (source of truth) |
| `icon-16.png` - `icon-512.png` | App icons at standard sizes |

The app icon is the Roulette mark (six petals and a hub) in black on a white rounded tile with a faint grey edge. The website keeps its own copies in `apps/website/public`. `logo.svg` is the source; the PNGs are rendered from it, at the same sizes as the Electron and Tauri icons.
