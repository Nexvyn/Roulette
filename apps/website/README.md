# Lyra — Website

The landing page for Lyra. Built with Next.js (App Router) and Tailwind CSS.

## Run

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

## Structure

```
src/app/
  layout.tsx    — root layout and metadata
  page.tsx      — landing page
  globals.css   — Tailwind base styles
public/
  logo.svg      — Lyra logo
  favicon.ico   — browser favicon
```
