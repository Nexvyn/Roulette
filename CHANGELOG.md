### Added

- Lyra monorepo — Electron, Tauri, and website in one repo
- Menu bar tray with live port count badge
- Auto-detection of local dev servers (ports 1024–49151)
- Process info: name, project folder, git branch, uptime
- Kill, open, copy URL/port actions per entry
- Kill all ports at once
- Rename and pin ports (persists across restarts)
- Search/filter bar (/ to focus, Esc to clear)
- Sort by port, name, or uptime
- Configurable scan interval (2/5/10/30 seconds)
- Launch at login toggle
- Dark mode (system theme)
- Onboarding flow
- Diagnostics panel
- Next.js landing page (website)
